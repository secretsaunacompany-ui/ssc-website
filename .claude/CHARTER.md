# SSC Website — Charter

**Purpose.** The public face of Secret Sauna Company at secretsaunacompany.ca: a static site that shows what Lee builds, prices it honestly from the canonical price sheet, and turns a visitor into a delivered quote request, so that inquiries arrive without anyone watching a dashboard.
**For.** Prospective SSC sauna buyers in the Sea-to-Sky and beyond configuring and requesting a quote; Lee Salo as owner-builder (and Anthony as co-owner) who must be able to trust every price and claim on it.
**Done looks like.** A quote submitted through the configurator reliably lands in the SSC inbox (and a weekly zero-submission alarm fires when it does not). Every price on the site matches the canonical models.json by construction, not by manual discipline. The site reads in the architecture-studio register Lee approved, with no external asset or font origins, and the test suites stay green with zero waivers.
**Non-goals.** It does not own price truth: prices derive from ~/marvin canonical models.json, never edited on the site alone. It does not carry operations surfaces: the orphaned analytics stack was deleted 2026-07-28 in favour of the shared ssc-ops tracker, and the booking admin API and /admin dashboard belong to SSC Booking's charter wherever the code sits. It does not sell in the lit-up-button, corny-headline register; Lee rejected that explicitly in the 2026-07 brief.
**Phase arc.** 1. Static site live on production at secretsaunacompany.ca (2025-12-15, the founding). 2. Capture the live Netlify SPA into a repo and convert to an Eleventy multi-page site for SEO (Feb 2026), a milestone, not the founding; gate: production parity on Netlify. 3. Template/CSS/JS consolidation (Feb 2026; the booking admin API and /admin dashboard added in this era are owned by SSC Booking's charter); gate: brand-critic review passed. 4. Redesign Wave A: rebuilt quote funnel, type and colour system, repricing, fail-closed visual-diff harness (Jul 2026); gate: Formspree receipt proven and models.json v2 parity green. 5. Self-host all media off Cloudinary (Aug 2026) (here); gate: zero external image references, account deleted post Aug 15. 6. Wave B: mobile gutters, composition and copy pages, case studies, configurator renders; gate: Lee's remaining fact answers and client case-study agreements.
**Drift tripwires.** Scope: has the repo grown a feature that is not a page, a quote path, or a price display (e.g. payroll, booking admin, ops tooling, a second analytics store)? Audience: is any page now written for search engines, critics, or other builders rather than a person deciding whether to buy a sauna from Lee? Built-for-the-builder: has a session spent more effort on harness, tooling, or instrumentation than on anything a visitor can see or submit, two releases in a row?
Founded 2025-12-15. Rewritten only with Lee's approval.
