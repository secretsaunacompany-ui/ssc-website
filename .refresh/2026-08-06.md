## What was deliberately left (the "no" list)

1. **Package-toggle wipes a pre-package à-la-carte pick** (js/modal.js wasOn
   branch). A visitor who chooses Cedar a-la-carte, tries the Premium package,
   then unchecks it, loses the Cedar pick to the group default. Money is never
   wrong — the reset lands on $0, summary always matches total — so the damage
   is one visible lost click. Remembering per-slot pre-package state is more
   machinery than that justifies. The code comment now documents the sacrificed
   ordering honestly instead of denying it exists.

2. **Analytics tracker's defer ordering couples render boot to a third-party
   download** (scripts.njk + init.js). A stalled ssc-ops response delays
   hero/nav visibility site-wide — contradicting analytics.js's own "must never
   break the funnel" doctrine. BUT the ordering is load-bearing: WP-0a's
   double-count suppression requires init.js's submit listener to register
   before the tracker's (registration order = dispatch order). The naive fix
   (async) resurrects the double-count. A real fix (dynamic injection after
   listener bind, or moving the boot off DOMContentLoaded) is a design task for
   a Wave B batch, not a cleanup. Left alone, hazard documented here.

3. **map.js inline style literals** (#c4a57b ×8 = --ember by coincidence of
   value, off-system #4A90E2, 'Outfit' by name). Genuine token drift waiting to
   happen, but the popups render in Leaflet's injected DOM where a class-based
   restyle is a real visual-change risk, the content is static first-party, and
   no suite watches open popups. Worth a small deliberate batch (move to
   .map-pin classes) when /locations/ is next touched — not a drive-by.

4. **Gallery hover/overlay CSS duplicated** between .gallery-mosaic scoped and
   bare .gallery-item rules (~30 identical lines). Both families live; the
   scoped copies merely re-assert at higher specificity. Removable, but the
   harness ceremony to certify the merge exceeds the value of 30 stable lines.
   Counterweight recorded: the model-index vs compare-ledger subgrid twin is
   DELIBERATE ("the two ledgers should read as the same instrument") — leave it.

5. **sauna.njk's static heater markup shows S6/S8 values under a comment
   claiming it is the S4 default** (latent only — handleHeaterOptions() rewrites
   before paint; modal unreachable without JS). Fixing it moves the price-table
   hash → prices-version ceremony + dom-integrity certificate. DEFERRED to the
   next pricing-window batch per the hands-off-pricing-files constraint. The
   next pricing session should carry it.

6. **Verified Chesterton fences, explicitly not "fixed":** `rm -rf dist` in the
   build command (kills the Netlify publish-dir resurrection bug, 2026-07-28);
   booking-ops.html/js passthrough (ops console is meant to be served;
   OPS_ADMIN_TOKEN fails closed — verified 401 live); style-src 'unsafe-inline'
   (required by booking-ops inline styles + page background-images; tightening
   is a project); the non-constant-time token compare in booking-admin
   (theoretically timing-unsafe, practically irrelevant over serverless jitter
   for a 64-hex token); the models-json selftest's in-place mutation (defended
   three ways, restore verified byte-for-byte — its scary shape is its point);
   the 188-entry dom-integrity whitelist with no expiry (range-scoping is
   STRICTLY STRONGER than calendar expiry: entries are inert outside their
   exact baseline..candidate pair and unconsumed in-scope entries fail the
   run — it is an attribution ledger, not debt); capture.mjs's Range-header
   cache bug documentation (matches the code exactly; video is stubbed before
   the cached-host rule so determinism provably doesn't rest on the buggy
   path — the ROADMAP deferred entry is accurate as written, nothing owed).

7. **The five suites' per-suite mutate() helpers were NOT unified** in the B3

8. **connect-src unpkg.com kept** in the CSP trim despite Leaflet loading via
